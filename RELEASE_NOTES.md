# TypLens-V1 v1 — native Typst formula recognition

Initial experimental model-only release of the native SX checkpoint.
Choose the FP32 ONNX archive for best reviewed quality or INT8 for a smaller
download. Both directly generate Typst and run in desktop-browser WASM.

The archives include their required metadata and licenses. They contain no
training code, training data, optimizer state, or runtime binaries.
Attach the two ONNX ZIP files from the sibling release-assets folder to this
GitHub release. The separate Hugging Face pack also contains FP32 safetensors.
